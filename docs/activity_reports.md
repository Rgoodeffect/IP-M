# نشاط الإدارات

## النموذج

"نموذج نشاط الإدارة" نموذج واحد لكل إدارة في كل فترة. نوع الفترة من الإعدادات، والافتراضي ربع سنوي.

| الجزء | المحتوى |
|---|---|
| الأنشطة المنفذة | النشاط، المجال، المستهدف، المنفذ، نسبة الإنجاز (محسوبة) |
| نسبة الإنجاز العامة | متوسط الأنشطة التي لها مستهدف |
| المؤشرات الرقمية | المؤشر، القيمة، الوحدة. تعبأ تلقائيا من "قالب مؤشرات الإدارة" إن وجد |
| النصوص | الصعوبات والمعوقات، وخطة الفترة القادمة |
| المرفقات | من الشريط الجانبي للنموذج |

لا يقبل النموذج إلا للإدارات المعلمة بـ "مطلوب منه تقرير نشاط".

## مسار الاعتماد

مسودة ← مراجعة مدير الإدارة ← مراجعة قسم الإحصاء والبيانات ← اعتماد التخطيط الاستراتيجي ← معتمدة ← مدرجة في التقرير.

| المرحلة | من ينفذها |
|---|---|
| إعداد النموذج وإرساله | منسق الإدارة (دور Department Coordinator مربوط بالإدارة) |
| مراجعة مدير الإدارة | المستخدم المحدد في حقل "المسؤول" في سجل الإدارة فقط (يحتاج دور منسق إدارة مربوطا بنفس الإدارة). إن لم يحدد مسؤول، يستطيع أي منسق للإدارة تنفيذها |
| مراجعة الإحصاء | قسم الإحصاء والبيانات |
| الاعتماد | قسم التخطيط الاستراتيجي أو مدير إدارة الاستثمار والتخطيط |

**إرجاع للتعديل:**

- متاح في كل مراحل المراجعة.
- يطلب النظام كتابة ملاحظات المراجعة قبل الإرجاع.
- تحفظ الملاحظات في سجل النموذج، وتظهر للمنسق أعلى النموذج.
- يرسل إشعار للمنسق.
- بعد إعادة الإرسال تمسح الملاحظات، فيتطلب أي إرجاع لاحق ملاحظات جديدة.

## الإشعارات

| الحدث | من يصله الإشعار |
|---|---|
| الإرسال لمدير الإدارة | مدير الإدارة |
| الوصول لمرحلة الإحصاء أو التخطيط | مستخدمو الدور المختص |
| الإرجاع للتعديل | منسقو الإدارة ومعد النموذج، مع الملاحظات |
| الاعتماد | منسقو الإدارة ومديرها |

ترسل الإشعارات داخل النظام دائما، وبالبريد إذا كان حساب البريد الصادر معدا.

## المواعيد والتذكير

- **الموعد النهائي** = نهاية الفترة + "الموعد النهائي (أيام بعد نهاية الفترة)" من الإعدادات. يمكن لكل إدارة أن يكون لها موعد خاص في سجلها.
- **التذكير اليومي** لمنسقي الإدارة ومديرها، طالما لم يرسل النموذج أو أرجع:
  - قبل الموعد بعدد الأيام المضبوط.
  - يوم الموعد نفسه.
  - بعد الموعد بشكل متكرر، حتى حد أقصى.
- **أيام التأخير**: تحسب حتى أول إرسال لمدير الإدارة.

## تقرير "حالة تقارير الإدارات"

لكل فترة يعرض:

- لكل إدارة: الحالة، والموعد النهائي، وتاريخ الإرسال، وأيام التأخير، ونسبة الإنجاز العامة.
- بطاقات ملخص: المطلوبة، الواردة، المعتمدة، لم ترفع، المتأخرة.

منسق الإدارة لا يرى في التقرير إلا إدارته.
