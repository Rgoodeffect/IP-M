# ترحيل سجل الشركات من Access

سكربت لمرة واحدة ينقل الشركات والشهادات من قاعدة Access الحالية إلى "سجل الشركات" في المنظومة.

## المتطلبات

- `mdbtools` على الخادم لقراءة ملف `.accdb` مباشرة:

  ```bash
  sudo apt-get install mdbtools
  ```

- أو بدلا من ذلك: مجلد فيه ملف CSV لكل جدول (`<اسم الجدول>.csv` بترميز UTF-8).

## الخطوات

### 1. معرفة أسماء الجداول والأعمدة

```bash
mdb-tables -1 /path/registry.accdb
mdb-export /path/registry.accdb <اسم الجدول> | head -3
```

### 2. إعداد ملف المطابقة

انسخ `loc_planning/investment_registry/migration/mapping.example.json` وعدل فيه:

- `table`: اسم جدول الشركات وجدول الشهادات.
- `columns`: على اليسار حقل المنظومة، وعلى اليمين اسم العمود في Access. احذف ما لا يوجد له مقابل.
- `status_values` و`classification_values`: تحويل القيم القديمة إلى قيم المنظومة.
- `company_ref_field`: كيف تربط الشهادة بالشركة.
  - `legacy_id`: المعرف القديم للشركة.
  - `registration_no`: رقم القيد.
- `default_classification`: التصنيف الذي يعطى للشركات التي لا تصنيف لها.

### 3. التشغيل التجريبي (dry run)

لا يحفظ شيء في هذا الوضع. يكتب تقرير CSV بكل الأخطاء والتحذيرات.

```bash
bench --site <site> execute loc_planning.investment_registry.migration.access_import.run \
  --kwargs "{'source': '/path/registry.accdb', 'mapping': '/path/mapping.json'}"
```

يحفظ التقرير في `sites/<site>/private/files/loc_registry_migration_dryrun_<الوقت>.csv`، وأعمدته:

| العمود | المحتوى |
|---|---|
| `level` | ERROR / WARNING / INFO |
| `entity` | company / certificate / classification / series |
| `source_row` | رقم السطر في الجدول المصدر |
| `key` | رقم القيد أو رقم الشهادة |
| `message` | وصف المشكلة |

### 4. التشغيل الفعلي

أضف `'dry_run': 0` إلى الأمر السابق. يمكن إعادة التشغيل بأمان: السجلات الموجودة مسبقا تتخطى ولا تتكرر.

## القواعد المطبقة

| البند | القاعدة |
|---|---|
| رقم القيد ورقم الشهادة | يبقيان كما هما ويصبحان اسم المستند في المنظومة |
| الأرقام الجديدة | نمط رقم القيد في الإعدادات (`REG-.#####`) يرفع تلقائيا فوق أعلى رقم مرحل يستخدم نفس البادئة |
| تكرار يمنع الاستيراد (خطأ) | رقم القيد، الرقم الضريبي، رقم السجل التجاري |
| تكرار يستورد مع تحذير | تشابه الاسم بعد توحيد الكتابة العربية (الهمزات، التاء المربوطة، الألف المقصورة، التشكيل، كلمة "شركة"...) |
| الشهادات الصادرة | تستورد معتمدة (بدون إعادة مسار الاعتماد)، مع رمز تحقق جديد يعمل في صفحة التحقق |
| الشهادة التي انتهى تاريخها | حالتها "منتهية" |
| الشهادة الملغاة | تبقى ملغاة مع سببها، أو مع "مرحل من النظام السابق" إن لم يوجد سبب |
| التصنيفات غير الموجودة | تنشأ تلقائيا. يمكن منع ذلك بـ `create_missing_classifications: false` |
| النصوص | يزال منها التشكيل والتطويل، وتوحد الأرقام العربية إلى غربية في المعرفات |
